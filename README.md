# PACE — Port-cost Assurance & Control Engine

선박대리점이 PDA·FDA·청구서·작업기록·요율 근거를 기항별 비용항목에 연결하고, 선사·선박관리사가 차액과 미확인 근거를 검토하는 공모전용 프로토타입입니다.

직접 사용자는 등록 선박대리점의 Ships Agency Operator 또는 DA 담당자이며, 검토 사용자는 선사·선박관리사의 운항·재무 담당자와 승인권자입니다. 첫 현장 PoC는 기업규모로 대상을 정하지 않고, 반복 기항 관계와 익명 데이터 제공이 가능한 선사 또는 선박관리사 1곳과 계약 선박대리점 1곳을 공동 단위로 삼습니다.

AI는 비정형 문서에서 비용항목과 근거 후보를 추출·연결합니다. 합계, 수량×단가, 중복, 증빙 존재 여부와 요율 조건은 규칙으로 점검합니다. 차이를 오류나 과다청구로 확정하지 않으며, 최종 정산·지급 판단은 선사 측 권한자가 수행합니다.

## 시연 범위

- 프로세스 시연(`/flow`): 가상 문서 수신부터 선사·대리점 공동 검토까지 5단계로 안내
- 문서 시작(`/app/documents`): PDA·RDA·공급자 인보이스·SOF·FDA로 구성한 6쪽 가상 문서(Synthetic Document)를 확인하고 한 번의 클릭으로 정답셋 기반 워크스페이스 구성
- 자유 업로드 베타: 텍스트형 PDF의 원문·비용 키워드·금액 후보 확인
- Evidence Graph: 사건·비용·증빙·요율·승인 근거 연결
- Cost Twin: 선택한 기항 변화에 따른 예상 FDA 갱신
- 공동 검토: 대리점이 정리한 차액과 부족 근거를 선사 담당자가 확인
- 검증(`/app/verify`): 가상 기항 통제와 공개요율의 출처·적용조건 검증 절차를 분리해 확인

기항은 가상 기항(Synthetic Demo), 문서는 가상 문서(Synthetic Document), 계산 규칙은 Demo Rule입니다. `Demo Rule`은 국내 표준요율이 아니며, 실제 적용 시 계약·요율·작업 사실을 확인해야 합니다. 기본 흐름은 가상 문서와 사전에 정의한 정답셋을 함께 사용하므로 임의 문서 정확도 성과를 뜻하지 않습니다. 자유 업로드 기능은 텍스트 레이어가 있는 PDF의 브라우저 내 추출까지 지원합니다. 스캔 PDF OCR, 표 구조 복원, 원문 영역 하이라이트와 정확도 평가는 아직 구현하지 않았습니다.

## PoC 진입 조건

현장 PoC는 다음 조건을 모두 충족하는 경우에만 추진합니다.

1. 익명화한 PDA·FDA·청구서·작업기록을 제공할 수 있다.
2. 선박대리점과 선사·선박관리사 양측에 검토 담당자가 있다.
3. 기존 시스템 이후에도 반복적인 문서 연결·재확인 단계가 남아 있다.
4. 기항 ID와 비용항목 ID로 문서와 근거를 연결할 수 있다.

조건을 충족하지 못하거나 기존 시스템이 동일 업무를 충분히 자동화한다면 해당 기업에는 도입하지 않습니다.

## 로컬 실행

```bash
npm install
npm run dev
```

기본 주소는 `http://localhost:5173/`입니다.
