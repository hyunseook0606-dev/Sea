# PACE AI Cost Review Agent

PACE 전용 합성 벤치마크입니다. 기존 SEA 스케줄 추출 모델의 수치를 재사용하지 않습니다.

## Agent 구성

1. 도메인 용어사전으로 보강한 문자 2~5그램 TF-IDF 모델이 서로 다른 비용 표현을 6개 표준 비용항목에 매핑합니다.
2. 같은 기항에서 모델이 분류한 공급자 문서를 비용항목의 증빙 후보로 연결합니다.
3. 통제 계층이 증빙 누락, 수량×단가 불일치와 중복 인보이스를 검사합니다.
4. 이상이 있거나 모델 확신도가 낮으면 자동확정하지 않고 담당자 검토 대상으로 남깁니다.

## 평가

```powershell
python pace_ai/evaluate_agent.py
```

- 고정 시드 2609
- 합성 시나리오 그룹 30개(실제 기항문서가 아님)
- 코드 생성 학습문장 600개
- 합성 비용 레코드 180개
- 통제 오류 45개
- 비용 클래스 6개

결과는 `reports/metrics.json`과 `reports/predictions.jsonl`에 저장됩니다.

## 해석 제한

- 실제 기항 스케줄이나 기업 문서를 수집한 데이터셋이 아닙니다.
- 30개는 ETA·ETB·ETD 등이 포함된 실제 기항문서가 아니라 합성 레코드의 그룹 키입니다.
- OCR이나 스캔 문서 레이아웃 복원 성능이 아닙니다.
- 통제된 템플릿과 도메인 사전을 사용하므로 현장 문서보다 쉬운 시험일 수 있습니다.
- 비용 의미 매핑은 학습 모델, 예외 탐지는 결정형 통제입니다.
- 실제 검토시간과 수정률은 참여기업 PoC에서 별도로 측정해야 합니다.
